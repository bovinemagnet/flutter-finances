= Repository layout
Paul Snow
:revnumber: 0.0.0

The repository is organised as follows. The server and `finance_store` packages are planned; the Dart domain package, the Flutter shell and the shared specification are the current foundation.

[source,text]
----
pubspec.yaml                      Dart pub workspace root
spec/fixtures/*.json              Shared golden fixtures (schemaVersion 1)
spec/sync/protocol.md             Sync protocol, version 1
packages/finance_core/            Pure Dart domain, no Flutter, no IO
packages/finance_store/           Encrypted SQLite persistence, outbox, file vault, sync client
apps/finance_app/                 Flutter client (Linux, Windows, macOS, iOS, Android)
server/                           Spring Boot modular monolith (Gradle subproject)
  finance-core/                   Java parity of shared financial rules (runs spec fixtures)
  app/                            API and worker
src/docs/                         This Antora component
----

[cols="1,3",options="header"]
|===
| Path | Purpose

| `packages/finance_core` | Financial rules: money, journals, drafts, projection, corrections, reconciliation, codecs
| `packages/finance_store` | Planned: encrypted database, outbox, receipt vault and sync client
| `apps/finance_app` | Adaptive UI (`lib/app`), platform services and adapters (`lib/platform`)
| `server` | Planned: workspace, sync, ledger, receipts, imports, exports and jobs modules
| `spec` | Executable contract shared by the Dart and Java implementations
|===

The technology stack is recorded in xref:architecture:adr-001-technology-stack.adoc[]; the fixture contract in xref:architecture:shared-fixtures.adoc[].
